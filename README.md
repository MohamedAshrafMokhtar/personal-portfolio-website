## 🌟 Overview

Welcome to the source code for my personal developer portfolio website! Built completely from scratch using **vanilla HTML5, CSS3, and JavaScript**, this project serves as my professional hub to showcase my software engineering background, interactive project walkthroughs, and contact channels. 

Rather than relying on heavy front-end frameworks or pre-built templates, this site was custom-coded to emphasize clean DOM manipulation, responsive design, and smooth user experience (UX).

---

## ✨ Key Features

* **Dynamic Modal Project Viewer (`script.js`):** Features a modular JavaScript architecture (`showModal()`) that dynamically injects titles, descriptions, image galleries, and video walkthroughs on demand without cluttering the markup.
* **Immersive Design & Styling:** Built with a custom CSS layout, CSS keyframe animations (`fadeIn` and `slideIn`), Google Fonts (`Poppins` and `Anton`), and a fixed, looping background video layer.
* **Interactive UI/UX:** Includes event-driven click-outside-to-close modals, hover states, and fully responsive structural transitions.
* **Direct Professional Connectivity:** Integrated quick-access links for GitHub, LinkedIn, direct email, and telephone communication.

---

## 🛠️ Tech Stack

* **Markup:** Semantic HTML5 (`<video>`, structural containers, custom modal overlays)
* **Styling:** Advanced CSS3 (Flexbox, custom properties, keyframe animations, responsive layering)
* **Logic:** Vanilla JavaScript (ES6+ DOM manipulation, event listeners, dynamic state rendering)
